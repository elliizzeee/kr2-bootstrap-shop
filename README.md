# Контрольная работа №2

Тема: «CSS-фреймворки: разработка интерфейса на Bootstrap или альтернативном CSS-фреймворке».

## Описание проекта

**Wood & Resin** — сайт лесной эко-мастерской и глэмпинга. Проект позволяет пользователям выбрать домик для отдыха, записаться на творческие мастер-классы по работе с деревом и эпоксидной смолой, а также приобрести готовые изделия или заказать индивидуальную работу.

## Выполненные практические работы

### Практическая работа №9 (Bootstrap-сетка)
- Создан отдельный репозиторий `kr2-bootstrap-shop`.
- Подключён Bootstrap 5.3 через CDN и собственный файл `css/custom.css`.
- Разработана главная страница с использованием сетки (`container`, `row`, `col-*`), адаптивных классов и отступов (`g-*`, `my-*`, `p-*`).
- Создана шапка, навигация, hero-блок, блок преимуществ и подвал.

### Практическая работа №10 (Bootstrap-компоненты)
- Создана единая навигация (`navbar`) на всех страницах.
- Созданы страницы: каталог (`catalog.html`), карточки мастер-классов, форма заявки (`order.html`).
- Использованы компоненты: `card`, `btn`, `badge`, `alert`, `modal`, `form-control`, `form-select`, `input-group`, `form-check`, `accordion`, `carousel`.
- Добавлены модальные окна для быстрой записи и оформления покупки.

## 🚀 Самостоятельные доработки (для повышенной оценки)

Проект был значительно расширен сверх базового шаблона методических указаний:

1. **Уникальный визуальный стиль:** Создана тёмная «лесная» тема с использованием CSS-эффекта матового стекла (`backdrop-filter`), свечения заголовков (`text-shadow`) и глубокой древесной палитры.
2. **Расширение структуры:** Добавлены дополнительные страницы:
   - `houses.html` — домики с каруселями фотографий.
   - `gallery.html` — галерея в стиле Pinterest с поддержкой фонового видео.
   - `shop.html` — полноценный магазин готовых изделий с артикулами и уникальной модалкой.
   - `custom-gallery.html` — галерея индивидуальных работ на заказ.
3. **Кастомные компоненты:** Отзывы на главной странице реализованы в виде карусели с нестандартными рейтингами (ёлочки вместо звёзд).
4. **Интерактив и логика:**
   - Внедрена Яндекс.Карта с фильтром тёмной темы.
   - Настроена валидация форм (блокировка прошедших дат в календаре).
   - Автоматическая подстановка артикула товара при нажатии на кнопку «Купить».
   - Создан экран приветствия для погружения в атмосферу с возможностью включения фоновой музыки.

## Используемые технологии

- HTML5
- CSS3 (включая `backdrop-filter`, `user-select`, адаптивную верстку)
- JavaScript (базовый уровень для интерактива и валидации)
- Bootstrap 5.3.3
- Git / GitHub
