# Контрольная работа №2

Тема: «CSS-фреймворки: разработка интерфейса на Bootstrap или альтернативном CSS-фреймворке».

## Описание

«Лесная гавань» — учебный сайт загородного комплекса для семейного отдыха с каталогом домиков, карточкой домика и формой бронирования.

## Практическая работа 9

Выполнена главная страница на Bootstrap-сетке.

Реализовано:
- подключение Bootstrap через CDN;
- подключение `css/custom.css`;
- шапка страницы;
- Bootstrap-навигация;
- hero-блок на сетке;
- блок преимуществ;
- сетка популярных домиков;
- подвал страницы.
